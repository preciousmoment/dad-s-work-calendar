# Babamın İş Takvimi 🗓️

Günlük yevmiye ile çalışan babalarımız için geliştirilmiş, tek dokunuşla çalışan en basit dijital iş takvimi.

## 🚀 GitHub Pages Üzerinde Ücretsiz Yayınlama
1. GitHub hesabınızda **babamin-is-takvimi** adında yeni bir Genel (Public) repository açın.
2. `index.html`, `manifest.webmanifest`, `sw.js` ve `icons` klasörünü yükleyin.
3. **Settings > Pages** bölümüne gidin. Branch kısmını `main` seçip kaydedin.
4. Adresiniz hazır: `https://kullaniciadi.github.io/babamin-is-takvimi`

## 📲 Android Telefona Kurulum
1. Android telefonda **Google Chrome** açın.
2. Yukarıdaki GitHub Pages adresinize gidin.
3. Sağ üstteki **üç noktaya (⋮)** dokunun.
4. **"Uygulamayı Yükle"** veya **"Ana Ekrana Ekle"** seçeneğine basın.
5. İnternet bağlantısı olmasa dahi kesintisiz çalışacaktır!
